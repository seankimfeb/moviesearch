# 🎬 OMDB Movie Search App

A simple Spring Boot web app that lets users search for movies using the OMDB API.

## 💡 Features
- Search movies by title
- View movie details (year, genre, plot, rating)
- Graceful handling of missing or invalid results

## 🚀 How to Run Locally

```bash
Type:
$git clone https://github.com/seankimfeb/moviesearch.git
$cd moviesearch
$mvn clean install
$mvn spring-boot:run




## 🔧 Tech Stack
- Java + Spring Boot
- Thymeleaf
- OMDB API
- Maven
